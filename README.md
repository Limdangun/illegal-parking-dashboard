# 화성시 불법주정차 민원 최소화 의사결정 시스템

**수원대학교 캡스톤디자인2 | 에네레기파 (임단군 · 정예민 · 안유경) | 2026.05**

> 화성시 실단속 217,682건을 분석해 위험 지역 식별 → 맞춤 정책 대책 추천 → 단속 인원 수요 예측까지 지원하는 Streamlit 기반 정책 의사결정 대시보드

---

## 프로젝트 개요

불법주정차 단속 건수가 2024년 역대 최다(233,993건)를 기록하는 상황에서,
기존의 일괄 단속 방식으로는 통행불편 민원을 효과적으로 줄이기 어렵다는 문제에서 출발했습니다.

**3가지 핵심 질문**에 데이터로 답합니다:

1. **어디가 가장 위험한가?** → 행정동별 재보정위험도 산출 (실단속×0.65 + 민원×0.35)
2. **어떤 대책이 효과적인가?** → 위반유형별 자동 정책 권고 (CCTV 설치 / 단속 강화 / 안내계도)
3. **인력이 언제 얼마나 필요한가?** → Prophet + SARIMA 앙상블으로 6개월 단속 건수 예측

---

## 주요 분석 결과

| 항목 | 결과 |
|------|------|
| 최고 위험 지역 | 향남읍 (재보정위험도 6.87점) |
| CCTV 설치 시급 지역 | 금곡동 (공백지수 0.733) |
| 단속 집중 시간대 | 오후 3시 (33,188건) |
| 주요 위반유형 | 횡단보도 39.2% |
| 앙상블 예측 MAE | **1,451건 (MAPE 6.7%)** |
| 2026년 피크 예측 | 10월 21,276건 → 인력 증원 권고 |

---

## 핵심 지표 정의

| 지표 | 계산식 |
|------|--------|
| **재보정위험도** | MinMaxScaler(실단속비율)×0.65 + MinMaxScaler(민원비율)×0.35 → 0~10점 |
| **CCTV 공백지수** | 법정동별 민원비율 − 고정CCTV비율 |
| **앙상블 가중치** | w = (1/MAE) / Σ(1/MAE) — MAE 역수 가중 자동 산출 |

## 빠른 시작

```bash
# 1. 패키지 설치
pip install -r dashboard/requirements.txt

# 2. 대시보드 실행
streamlit run dashboard/app.py
# → http://localhost:8501 접속

# 3. 전처리 재실행 (원본 데이터 있을 때)
python run_preprocessing.py

# 4. 발표 PPT 재생성
python make_ppt_final.py
```

> **Note:** Prophet 최초 설치 시 cmdstan 자동 다운로드로 3~5분 소요됩니다.
