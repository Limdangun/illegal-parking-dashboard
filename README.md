# 화성시 불법주정차 민원 최소화 의사결정 시스템

**임단군** | 수원대학교 캡스톤디자인2 | 2026.05

> 화성시 실단속 217,682건을 분석해 **위험 지역 식별 → 맞춤 정책 대책 → 단속 인원 수요 예측**까지 지원하는 Streamlit 기반 정책 의사결정 대시보드

---

## 프로젝트 배경

불법주정차 단속 건수가 2024년 역대 최다(233,993건)를 기록하는 상황에서, 기존의 일괄 단속 방식으로는 통행불편 민원을 효과적으로 줄이기 어렵다는 문제에서 출발했습니다.

**데이터로 답하는 3가지 질문:**
1. **어디가 가장 위험한가?** → 행정동별 재보정위험도 산출
2. **어떤 대책이 효과적인가?** → 위반유형별 자동 정책 권고
3. **인력이 언제 얼마나 필요한가?** → Prophet + SARIMA 앙상블 예측

## 대시보드 구성 (5탭)

| 탭 | 내용 |
|----|------|
| 위험도 지도 | 행정동별 재보정위험도 Folium 지도 + 클릭 팝업 |
| 시간대 히트맵 | 요일×시간대 단속 집중 패턴 시각화 |
| 위반유형 대책 | 도넛차트 + 유형별 자동 정책 권고 (CCTV/단속/계도) |
| 전체 현황 | 연도별 추이, CCTV 공백지수 순위 |
| 예측 & 정책권고 | 6개월 앙상블 예측 + 인력 수요 권고문 자동 생성 |

---

## 핵심 지표 설계

```
재보정위험도   = MinMaxScaler(실단속비율) × 0.65
               + MinMaxScaler(민원비율)   × 0.35   → 0~10점

CCTV 공백지수  = 법정동별 민원비율 − 고정CCTV비율

앙상블 가중치  = (1 / MAE모델) / Σ(1 / MAE)       → MAE 역수 자동 산출
```
